## Machine Learning

- 공학적 접근방법 : T, P, E
- 특정 작업 T에 대한 프로그램의 성능을 P로 측정했을 때, 경험 E로 인해 성능이 향상되었다면 프로그램은 작업T와 성능평가P에 대해 경험 E로 학습한 것

- input: 처리할 Data
- output: 연산을 통해 처리한 결과
- label: input에 대한 정답 (목표)

### 유형

- Supervised Learning: label이 있는 데이터로 학습 (결과로 데이터 예측)
- unsupervised Learning: lable이 없는 데이터로 학습 (공통 구조/특징 예측)
- Reinforcement Learning: 보상시스템으로 학습

#### Neuron / Perceptron

- input
- activation function: 특정 값 기준으로 0/1 구분 (RELU, sigmoid)
- output
