# EX01-20 고수준 파일 입출력으로 파일 복사

관련 개념: [[Linux/개념/Linux 파일 입출력|Linux 파일 입출력]]

관련 빌드 규칙: [[Linux/과제/0921/common.mk|common.mk 전체 분석]]

```c
#include <stdio.h>

#include <stdlib.h>

#include <unistd.h>

#include <errno.h>

#include <string.h>

#include <sys/types.h>

#include <sys/stat.h>

#include <fcntl.h>

  

#define MAX_BLOCK_SIZE 4096

  

int main(int argc, char **argv)

{

    int block_size;

    off_t i, file_size, block_count;

    size_t remainder, copied = 0;

    FILE *src_fp, *dst_fp;

    char *src_name, *dst_name;

    char buf[MAX_BLOCK_SIZE];

    struct stat src_stat;

  

    if(argc != 4) {

        printf("usage: %s {src file} {dst file} {block size in bytes}\n", argv[0]);

        return EXIT_FAILURE;

    }

    printf("running %s %s %s %s\n", argv[0], argv[1], argv[2], argv[3]);

  

    src_name = argv[1];

    dst_name = argv[2];

    block_size = atoi(argv[3]);

  

    if(block_size > MAX_BLOCK_SIZE) {

        printf("error: block size if too big (maximum is %d bytes (%d)\n", MAX_BLOCK_SIZE, __LINE__);

        return EXIT_FAILURE;

    }

  

    stat(src_name, &src_stat);

    file_size = src_stat.st_size;

    block_count = file_size / block_size;

    remainder = (size_t)(file_size % block_size);

  

    /* open source file */

    src_fp = fopen(src_name, "r");

    if(src_fp == NULL) {

        printf("error: %s (%d)\n", strerror(errno), __LINE__);

        return EXIT_FAILURE;

    }

  

    /* open destination file */

    dst_fp = fopen(dst_name, "w");

    if(dst_fp == NULL) {

        printf("error: %s (%d)\n", strerror(errno), __LINE__);

        return EXIT_FAILURE;

    }

  

    /* copy */

    for(i = 0; i < block_count; i++) {

        fread(buf, (size_t)block_size, 1, src_fp);

        fwrite(buf, (size_t)block_size, 1, dst_fp);

        copied += (size_t)block_size;

    }

  

    if(remainder > 0) {

        fread(buf, remainder, 1, src_fp);

        fwrite(buf, remainder, 1, dst_fp);

        copied += remainder;

    }

  

    /* close */

    fclose(src_fp);

    fclose(dst_fp);

  

    printf("%lu bytes copied\n", copied);

  

    return EXIT_SUCCESS;

}
```

## 프로그램 목적

원본 파일을 사용자가 지정한 블록 크기로 나누어 읽고 대상 파일에 복사한다. `FILE *`와 `fopen()`, `fread()`, `fwrite()`, `fclose()`를 사용하는 **고수준 파일 입출력** 예제이다.

```bash
./EX01-20 원본파일 대상파일 블록크기
```

## 입력 인수

| 인수 | 저장 변수 | 의미 |
|---|---|---|
| `argv[1]` | `src_name` | 원본 파일 경로 |
| `argv[2]` | `dst_name` | 대상 파일 경로 |
| `argv[3]` | `block_size` | 한 번에 복사할 바이트 수 |

`argc`는 실행 파일명을 포함해 `4`여야 한다. 블록 크기는 `atoi()`로 문자열에서 정수로 변환하며 최대 `4096`바이트로 제한한다.

## 주요 변수

| 변수 | 역할 |
|---|---|
| `file_size` | 원본 파일 전체 크기 |
| `block_count` | 완전한 블록의 개수 |
| `remainder` | 블록 단위로 나눈 뒤 남는 바이트 수 |
| `copied` | 복사했다고 계산한 전체 바이트 수 |
| `buf` | 데이터를 임시 저장하는 4096바이트 버퍼 |
| `src_fp`, `dst_fp` | 원본과 대상 파일 스트림 |

## 파일 크기와 블록 계산

```c
stat(src_name, &src_stat);
file_size = src_stat.st_size;
block_count = file_size / block_size;
remainder = (size_t)(file_size % block_size);
```

```text
전체 파일 = 완전한 블록 × block_size + remainder
```

- `block_count`: `block_size`만큼 복사할 반복 횟수
- `remainder`: 마지막에 별도로 복사할 남은 크기

## 파일 열기

```c
src_fp = fopen(src_name, "r");
dst_fp = fopen(dst_name, "w");
```

- 원본은 읽기 모드로 연다.
- 대상은 쓰기 모드로 열며, 파일이 없으면 생성하고 이미 있으면 기존 내용을 비운다.
- `fopen()`이 실패하면 `NULL`을 반환하며 `errno`와 `strerror()`로 원인을 출력한다.

## 블록 복사

```c
for (i = 0; i < block_count; i++) {
    fread(buf, (size_t)block_size, 1, src_fp);
    fwrite(buf, (size_t)block_size, 1, dst_fp);
    copied += (size_t)block_size;
}
```

`block_size`바이트를 하나의 요소로 보고 `block_count`회 반복하여 복사한다.

```c
if (remainder > 0) {
    fread(buf, remainder, 1, src_fp);
    fwrite(buf, remainder, 1, dst_fp);
    copied += remainder;
}
```

완전한 블록을 모두 복사한 뒤 남은 바이트가 있으면 마지막에 한 번 더 복사한다.

## 전체 실행 흐름

```text
인수 확인
   ↓
블록 크기 변환 및 최대 크기 확인
   ↓
stat()으로 원본 파일 크기 확인
   ↓
block_count와 remainder 계산
   ↓
원본과 대상 파일 열기
   ↓
완전한 블록 반복 복사
   ↓
남은 바이트 복사
   ↓
두 파일 닫기
   ↓
복사한 바이트 수 출력
```

## 주의할 점

| 위치 | 문제점 | 필요한 처리 |
|---|---|---|
| `atoi(argv[3])` | 숫자가 아니거나 `0` 이하인지 확인하지 않음 | 변환 결과와 범위 검사 필요 |
| `file_size / block_size` | `block_size`가 `0`이면 0으로 나누기 발생 | 계산 전에 `block_size > 0` 확인 |
| `stat()` | 반환값을 확인하지 않음 | 실패 시 오류 출력 후 종료 |
| `fread()`·`fwrite()` | 반환값을 확인하지 않음 | 실제 읽고 쓴 요소 수 확인 |
| 대상 `fopen()` 실패 | 이미 연 원본 스트림을 닫지 않음 | 오류 종료 전에 `fclose(src_fp)` 호출 |
| `copied` | 실제 처리량이 아니라 요청한 크기만 더함 | 함수 반환값을 기준으로 계산 |
| `printf("%lu", copied)` | `size_t`의 이식 가능한 형식이 아님 | `%zu` 사용 |
| `fclose()` | 반환값을 확인하지 않음 | 닫기 및 버퍼 반영 실패 확인 |

Linux에서는 텍스트 모드와 바이너리 모드의 차이가 없지만, 이식성을 고려하면 파일 복사에는 `"rb"`, `"wb"`를 사용할 수 있다.

## 핵심 정리

- `stat()`으로 파일 크기를 구하고 블록 수와 나머지를 계산한다.
- 완전한 블록을 반복 복사한 뒤 남은 바이트를 별도로 복사한다.
- `fread()`와 `fwrite()`의 반환값은 처리한 요소 개수이므로 반드시 확인해야 한다.
- `common.mk`에서는 `TARGET1 = EX01-20`으로 지정하여 컴파일과 링크 규칙을 재사용할 수 있다.
