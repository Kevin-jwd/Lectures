# 명령 치환

**명령 치환(command substitution)**은 명령을 먼저 실행한 뒤, 그 명령의 **표준 출력 결과를 문자열로 바꾸어 사용하는 기능**이다. 명령의 결과를 변수에 저장하거나 다른 명령의 일부로 사용할 수 있다.

## 문법

```bash
$(명령어)
```

백틱을 사용하는 이전 문법도 있지만, 중첩하기 쉽고 읽기 편한 `$()` 형식을 권장한다.

```bash
`명령어`
```

## 사용 예

현재 경로를 변수에 저장한다.

```bash
current_dir=$(pwd)
echo "$current_dir"
```

다른 명령의 인수나 문자열 안에서도 사용할 수 있다.

```bash
echo "현재 경로: $(pwd)"
```

```bash
files=$(ls)
echo "$files"
```

`ls`의 표준 출력이 `files` 변수에 저장된다. 변수를 `"$files"`처럼 큰따옴표로 감싸면 결과의 줄 구분과 공백이 의도치 않게 나뉘는 것을 줄일 수 있다.

> 명령 치환은 명령의 **표준 출력**을 사용하며, 결과 끝의 줄바꿈 문자는 제거된다.
