# 공유 라이브러리 파일명 구조

관련 개념: [[Linux/개념/GNU 툴체인과 빌드 과정|GNU 툴체인과 빌드 과정]]

## 시험 핵심

```text
링크 이름       SONAME          실제 파일명
libmycal.so → libmycal.so.1 → libmycal.so.1.2
```

| 구분 | 사용 시점 |
|---|---|
| 링크 이름 | 빌드할 때 링커가 검색 |
| SONAME | 응용 프로그램에 기록 |
| 실제 파일명 | 실제 라이브러리 코드 저장 |

- 실행 시 동적 링커는 SONAME을 기준으로 라이브러리를 찾는다.
- 링크 이름과 SONAME은 일반적으로 실제 파일을 가리키는 심볼릭 링크이다.
