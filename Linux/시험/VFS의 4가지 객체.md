# VFS의 4가지 객체

관련 개념: [[Linux/개념/Linux 파일시스템|Linux 파일시스템]]

| 객체 | 시험 핵심 |
|---|---|
| `super_block` | **마운트된 파일시스템 전체**의 정보 |
| `inode` | **개별 파일·디렉터리**의 메타데이터. 파일 이름은 저장하지 않음 |
| `dentry` | **디렉터리 항목**: 이름을 inode에 연결하고 경로 탐색에 사용 |
| `file` | **열린 파일**의 상태: 접근 모드, 현재 파일 위치 등 |

```text
파일시스템 전체: super_block
경로의 이름:     dentry ──▶ inode: 파일의 정보
파일을 열면:     파일 디스크립터 ──▶ file: 열린 상태
```

**구별:** `inode`는 파일 자체의 정보이고, `file`은 그 파일을 **열어서 사용하는 상태**이다.
