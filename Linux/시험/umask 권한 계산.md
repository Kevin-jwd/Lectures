# umask 권한 계산

관련 개념: [[Linux/개념/Linux 파일 접근 권한|Linux 파일 접근 권한]]

## 시험 핵심

```text
최종 생성 권한 = mode & ~umask
```

`umask`는 권한을 부여하는 값이 아니라 `mode`에서 제거할 권한을 나타낸다.

## 예시 문제

다음 `mode`와 `umask 0027`이 주어졌을 때 새 파일의 최종 권한을 8진수와 2진수로 구하시오.

```c
mode_t mode = S_IRUSR | S_IWUSR |
              S_IRGRP | S_IWGRP |
              S_IROTH | S_IWOTH;
```

### 풀이

권한 매크로를 합치면 `mode`는 `0666`이다.

```text
mode                0666 = 110 110 110
umask               0027 = 000 010 111
~umask (권한 9비트) 0750 = 111 101 000
--------------------------------------
mode & ~umask       0640 = 110 100 000
```

**정답: `0640`, `110 100 000`, `rw-r-----`**
