# GCC 빌드 옵션

관련 개념: [[Linux/개념/GNU 툴체인과 빌드 과정|GNU 툴체인과 빌드 과정]]

## 시험 핵심

```text
.c → .i → .s → .o → 실행 파일
```

| 옵션 | 멈추는 단계 | 결과 |
|---|---|---|
| `-E` | 선행처리 | 표준 출력 |
| `-S` | 컴파일 | `.s` |
| `-c` | 어셈블 | `.o` |
| 옵션 없음 | 링크 | 실행 파일 |
| `-o 파일명` | 결과 이름 지정 | 지정한 이름으로 생성 |
| `-save-temps` | 전체 빌드 | `.i`, `.s`, `.o` 보존 |

```bash
aarch64-linux-gnu-gcc -c main.c -o temp.o
```

`main.c`를 링크하지 않고 `temp.o` 목적 파일로 만든다.
