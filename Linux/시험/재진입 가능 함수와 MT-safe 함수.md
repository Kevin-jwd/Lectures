# 재진입 가능 함수와 MT-safe 함수

관련 개념: [[Linux/개념/Linux 스레드|Linux 스레드]]

| 구분 | 시험 핵심 |
|---|---|
| **재진입 가능(reentrant)** | 함수 실행 중 같은 함수가 다시 호출되어도 각 호출이 간섭하지 않음 |
| **MT-safe** | 여러 스레드가 동시에 호출해도 결과가 올바름 |

**재진입 가능 ⇒ 일반적으로 MT-safe. MT-safe ⇒ 재진입 가능은 아님.** 내부 뮤텍스로 공유 상태를 보호하면 MT-safe일 수 있지만, 재호출 시 같은 잠금을 다시 기다리므로 재진입 가능하지 않을 수 있다.
