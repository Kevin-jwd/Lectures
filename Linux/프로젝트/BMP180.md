## 1. 온도/기압 측정 흐름 (Measurement Flow)

BMP180은 온도와 기압의 원시 데이터(Uncompensated Data)를 제공하며, 실제 물리량으로 변환하기 위해서는 보정 연산이 필요합니다.

1. **Start** — 측정 시작
    
2. **Start temperature measurement** — 온도 측정 명령 전송
    
3. **Wait 4.5ms** — ADC 변환 완료까지 최소 4.5ms 대기
    
4. **Read UT (Uncompensated Temperature)** — 보정되지 않은 원시 온도 데이터 읽기
    
5. **Start pressure measurement** — 기압 측정 명령 전송
    
6. **Wait 4.5ms (depending on mode)** — OSS 설정에 따른 기압 변환 시간 대기
    
    - OSS = 0: Ultra Low Power Mode (초저전력 모드)
        
7. **Read UP (Uncompensated Pressure)** — 보정되지 않은 원시 기압 데이터 읽기
    
8. **Calculate pressure and temperature** — 드라이버에서 보정 계수를 이용하여 실제 온도 및 기압 계산
    

**현재 구현 참고 사항**

현재 BMP180의 `read()`는 온도 전용 경로이므로 5~7번의 기압 측정 과정은 수행하지 않습니다.

## 2. 보정 계수 (Calibration Coefficients)

BMP180 내부 EEPROM에는 센서별로 공장에서 설정된 **11개의 보정 계수**가 저장되어 있습니다.

- **EEPROM contains 11 calibration coefficients.**
    
    - EEPROM에 총 11개의 보정 계수가 저장되어 있습니다.
        
- **Before the first calculation, the master should read these values from EEPROM.**
    
    - 최초 보정 연산을 수행하기 전에 마스터(Jetson)는 EEPROM에서 보정 계수를 읽어야 합니다.
        
- **Calibration coefficients**
    
    - AC1, AC2, AC3, AC4, AC5, AC6, B1, B2, MB, MC, MD
        

보정 계수는 센서마다 다르며, 드라이버 초기화 과정에서 한 번 읽어 메모리에 저장한 후 측정 시 재사용할 수 있습니다.

|보정 계수|레지스터 주소|자료형|
|---|---|---|
|AC1|0xAA~0xAB|signed 16-bit|
|AC2|0xAC~0xAD|signed 16-bit|
|AC3|0xAE~0xAF|signed 16-bit|
|AC4|0xB0~0xB1|unsigned 16-bit|
|AC5|0xB2~0xB3|unsigned 16-bit|
|AC6|0xB4~0xB5|unsigned 16-bit|
|B1|0xB6~0xB7|signed 16-bit|
|B2|0xB8~0xB9|signed 16-bit|
|MB|0xBA~0xBB|signed 16-bit|
|MC|0xBC~0xBD|signed 16-bit|
|MD|0xBE~0xBF|signed 16-bit|

## 3. 온도 및 기압 보정 계산 (Calculation of Pressure and Temperature)

데이터시트에 정의된 측정 및 보정 절차는 다음과 같습니다.

1. **Start** — 측정 및 보정 과정 시작
    
2. **Read Calibration Data from EEPROM**
    
    - EEPROM에 저장된 보정 계수 11개 읽기
        
    - 일반적으로 드라이버 초기화 시 한 번 수행
        
3. **Read Uncompensated Temperature (UT)**
    
    - `0xF4` 레지스터에 `0x2E` 기록
        
    - 최소 4.5ms 대기
        
    - 데이터 레지스터에서 UT 읽기
        
4. **Read Uncompensated Pressure (UP)**
    
    - `0xF4` 레지스터에 `0x34 + (oss << 6)` 기록
        
    - OSS = 0인 경우 최소 4.5ms 대기
        
    - 데이터 레지스터에서 UP 읽기
        
5. **Calculate True Temperature**
    
    - UT와 보정 계수를 이용해 실제 온도 계산
        
6. **Calculate True Pressure**
    
    - UP, 보정 계수 및 온도 보정 과정의 중간값을 이용해 실제 기압 계산
        
7. **Return to Step 3**
    
    - 다음 측정이 필요하면 3번부터 반복
        
    - 보정 계수는 일반적으로 다시 읽을 필요가 없음
        

**참고:** 기압 보정에는 온도 보정 과정에서 계산한 중간값 `B5`가 사용됩니다. 따라서 기압을 계산하려면 온도 보정 과정도 필요합니다.

## 4. 레지스터 구성 (Global Memory Map)

BMP180의 주요 레지스터와 역할은 다음과 같습니다.

|레지스터|주소|접근 권한|역할|
|---|---|---|---|
|`out_xlsb`|0xF8|Read Only|측정 결과의 확장 하위 바이트|
|`out_lsb`|0xF7|Read Only|측정 결과 하위 바이트|
|`out_msb`|0xF6|Read Only|측정 결과 상위 바이트|
|`ctrl_meas`|0xF4|Read/Write|온도·기압 측정 명령 및 설정|
|`soft_reset`|0xE0|Write|소프트웨어 리셋|
|`id`|0xD0|Read Only|장치 식별값 확인|
|`calib`|0xAA~0xBF|Read Only|11개 보정 계수 저장|

### 4.1 측정 결과 레지스터 (Output Registers)

- `out_msb`, `out_lsb`, `out_xlsb`는 ADC 측정 결과를 저장합니다.
    
- 온도와 기압은 동일한 결과 레지스터를 공유합니다.
    
- 어떤 측정 명령을 실행했는지에 따라 반환되는 데이터가 달라집니다.
    
- 온도 측정 시 2바이트, 기압 측정 시 최대 3바이트를 읽습니다.
    

### 4.2 측정 제어 레지스터 (ctrl_meas)

**SCO (Bit 5) — Start of Conversion**

- ADC 변환이 진행 중이면 `1`
    
- 변환이 완료되면 자동으로 `0`
    
- 측정 진행 상태를 확인할 수 있는 비트
    

**OSS (Bit 7:6) — Oversampling Setting**

기압 측정의 오버샘플링 설정을 결정합니다.

|OSS|측정 모드|변환 시간 (최대)|
|---|---|---|
|00|Ultra Low Power|4.5ms|
|01|Standard|7.5ms|
|10|High Resolution|13.5ms|
|11|Ultra High Resolution|25.5ms|

현재 프로젝트에서는 `OSS = 0`을 사용합니다.

### 4.3 소프트웨어 리셋 (soft_reset)

- `0xE0` 레지스터에 `0xB6` 기록
    
- Power-on Reset과 동일한 초기화 수행
    
- 센서를 소프트웨어적으로 재설정할 때 사용
    

### 4.4 장치 식별 레지스터 (id)

- 레지스터 주소: `0xD0`
    
- 고정값: `0x55`
    
- I2C 통신 및 BMP180 장치 식별에 사용
    

드라이버의 `probe()`에서 해당 값을 읽고 비교하여 장치를 검증할 수 있습니다.

### 4.5 보정 계수 레지스터 (Calibration Registers)

- 주소 범위: `0xAA~0xBF`
    
- 총 22바이트(11개 × 2바이트)
    
- 센서별 보정 계수 저장
    
- 실제 온도 및 기압 계산에 사용

## 5. Linux 드라이버에서의 처리 흐름

앞서 설명한 데이터시트의 측정 과정을 Linux 드라이버에 적용하면 다음과 같습니다.

**드라이버 초기화 (**`**probe()**`**)**

1. I2C 통신 기능 확인
    
2. Chip ID(`0x55`) 검증
    
3. 드라이버 데이터 구조체 초기화
    
4. Calibration 계수 11개 읽기
    
5. 사용자 공간 인터페이스 등록
    

**측정 요청 처리 (**`**read()**` **또는 IIO** `**read_raw()**`**)**

1. 사용자 공간에서 측정 요청
    
2. BMP180에 측정 명령 전송
    
3. ADC 변환 완료 대기
    
4. 원시 데이터 읽기
    
5. 보정 알고리즘 수행
    
6. 실제 온도 또는 기압 값을 사용자 공간에 전달
    

**핵심 정리**

BMP180은 보정되지 않은 ADC 측정값과 공장 보정 계수를 제공하며, Linux 드라이버가 이를 이용해 실제 온도 및 기압을 계산합니다. 초기화 과정과 측정 과정을 분리하면 불필요한 보정 계수 재읽
