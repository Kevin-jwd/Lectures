# Linux 파이프와 grep

관련 문제: [[Linux/예제/EX01-03 파일 및 텍스트 검색|EX01-03 파일 및 텍스트 검색]]

## 표준 입출력 *시험 출제* — [[Linux/시험/표준 입출력|시험 요약]]

Linux 명령어는 일반적으로 다음과 같은 입출력 통로를 사용한다.

| 구분 | 번호 | 기본 대상 |
|---|---:|---|
| 표준 입력(stdin) | 0 | 키보드 |
| 표준 출력(stdout) | 1 | 화면 |
| 표준 오류(stderr) | 2 | 화면 |

**표준 입출력**은 프로세스가 외부와 데이터를 주고받는 통로이다. 일반적인 PC 환경에서는 표준 입력에 키보드, 표준 출력과 표준 오류에 모니터가 연결된다.

- 명령 실행 결과는 표준 출력으로 전달된다.
- 오류 메시지는 표준 오류로 전달된다.
- 자식 프로세스는 부모 프로세스의 표준 입출력을 상속하므로, 보통 셸과 셸에서 실행한 명령은 같은 입출력 장치를 사용한다.

```bash
ls
```

디렉터리 목록이 표준 출력인 화면에 표시된다.

```bash
ls xxx
```

존재하지 않는 항목을 지정하면 오류 메시지가 표준 오류인 화면에 표시된다.

## 출력 리다이렉션: `>`, `>>`

**리다이렉션**은 표준 입출력의 기본 연결 대상을 다른 곳으로 바꾸는 기능이다. `>`와 `>>`를 사용하면 표준 출력을 화면 대신 파일로 보낼 수 있다.

| 기호 | 동작 |
|---|---|
| `>` | 파일에 새로 기록하며 기존 내용은 덮어씀 |
| `>>` | 기존 내용을 유지하고 파일 끝에 추가 |

```bash
ls -l > ls.txt
```

`ls -l`의 표준 출력 결과를 화면 대신 `ls.txt`에 기록한다.

```bash
echo "test failed" >> log.txt
```

`test failed`를 `log.txt`의 기존 내용 뒤에 추가한다.

## 입력 리다이렉션: `<`

`<`는 표준 입력을 키보드 대신 지정한 파일에서 받도록 변경한다.

```bash
cat
```

`cat`은 키보드로 입력받은 내용을 화면에 출력한다.

```bash
cat < ls.txt
```

표준 입력으로 키보드 대신 `ls.txt`를 사용하여 파일 내용을 화면에 출력한다.

## 표준 오류 리다이렉션: `2>`

`2>`는 파일 디스크립터 `2`인 표준 오류를 파일로 보낸다. 표준 출력과 표준 오류는 서로 독립적으로 리다이렉션할 수 있다.

```bash
grep conf /etc/*
```

리다이렉션하지 않으면 정상 결과와 오류 메시지가 모두 화면에 표시된다.

```bash
grep conf /etc/* > conf.txt
```

- 정상 결과: `conf.txt`
- 오류 메시지: 화면

```bash
grep conf /etc/* 2> error.txt
```

- 정상 결과: 화면
- 오류 메시지: `error.txt`

```bash
grep conf /etc/* > conf.txt 2> error.txt
```

- 정상 결과: `conf.txt`
- 오류 메시지: `error.txt`

## 표준 출력과 표준 오류 통합

`2>&1`은 표준 오류(`2`)를 현재 표준 출력(`1`)이 향하는 곳으로 보낸다.

```bash
grep conf /etc/* > all.txt 2>&1
```

표준 출력을 먼저 `all.txt`로 보낸 다음 표준 오류도 같은 곳으로 보내므로, 정상 결과와 오류가 모두 `all.txt`에 기록된다.

다음과 같이 간단히 작성할 수도 있다.

```bash
grep conf /etc/* &> all.txt
```

`&>`는 표준 출력과 표준 오류를 모두 지정한 파일로 보낸다.

## 파이프: `|`

파이프는 앞 명령어의 표준 출력을 뒤 명령어의 표준 입력으로 전달한다.

```bash
명령어1 | 명령어2
```

```bash
ls -l /etc | grep conf
```

1. `ls -l /etc`가 `/etc`의 목록을 출력한다.
2. 출력 결과가 `grep conf`의 입력으로 전달된다.
3. `conf`가 포함된 행만 화면에 출력된다.

파이프는 여러 개 연결할 수 있다.

```bash
ls -l /etc | grep conf | less
```

`conf`가 포함된 결과를 `less`로 페이지 단위로 확인한다.

## C 파이프 종류

C에서 사용하는 파이프는 생성 방식과 연결 대상에 따라 다음 세 가지로 구분한다.

- [[Linux/개념/Linux 이름 있는 파이프 FIFO|이름 있는 파이프(FIFO)]]: 파일 시스템에 이름이 있으며 `read()`, `write()` 사용
- [[Linux/개념/Linux 프로세스 파이프|프로세스 파이프]]: `popen()`으로 명령을 실행하고 `fread()`, `fwrite()` 사용
- [[Linux/개념/Linux 이름 없는 파이프|이름 없는 파이프]]: `pipe()`로 생성하며 `read()`, `write()` 사용

## 문자열 검색: `grep`

`grep`은 입력에서 지정한 문자열이나 패턴이 포함된 행을 찾는다.

```bash
grep [옵션] 패턴 [파일...]
```

```bash
cat /etc/passwd | grep sys
```

`/etc/passwd`에서 `sys`가 포함된 행을 출력한다.

파일을 직접 지정하면 불필요한 `cat`을 생략할 수 있다.

```bash
grep root /etc/passwd
```

`/etc/passwd`에서 `root`가 포함된 행을 출력한다.

## 주요 옵션

| 옵션 | 의미 |
|---|---|
| `-v` | 패턴이 포함되지 않은 행 출력 |
| `-i` | 영문 대소문자를 구분하지 않고 검색 |
| `-w` | 패턴과 정확히 일치하는 단어 검색 |
| `-c` | 패턴이 포함된 행의 수 출력 |
| `-r` | 하위 디렉터리를 포함하여 재귀 검색 |
| `-n` | 검색 결과에 행 번호 표시 |

### 패턴이 없는 행 검색: `-v`

`-v`는 지정한 패턴이 포함되지 않은 행을 출력한다.

```bash
grep -v root /etc/passwd
```

`/etc/passwd`에서 `root`가 없는 행을 출력한다.

```bash
cat /etc/passwd | grep sys | grep -v run
```

- `sys`가 포함된 행 선택
- 선택한 결과 중 `run`이 포함된 행 제외

### 여러 파일 검색

```bash
grep root /etc/*
```

`*`로 확장되는 `/etc`의 여러 항목에서 `root`를 검색한다. `*`의 동작은 [[Linux/개념/Linux glob 패턴|Linux glob 패턴]]과 관련된다.

```bash
grep -i sys /etc/*
```

영문 대소문자를 구분하지 않고 `sys`를 검색한다.

```bash
grep -w root /etc/*
```

문자열의 일부가 아닌 `root`라는 단어와 정확히 일치하는 행을 검색한다.

```bash
grep -c root /etc/*
```

각 파일에서 `root`가 포함된 행의 수를 출력한다.

### 하위 디렉터리와 행 번호 검색

```bash
grep -r root /etc
```

`/etc`의 하위 디렉터리까지 재귀적으로 검색한다.

```bash
grep -rn root /etc
```

재귀 검색 결과에 행 번호를 함께 표시한다.

## 여러 조건 연결

파이프로 `grep`을 연속해서 사용하면 모든 조건을 만족하는 행을 찾을 수 있다.

```bash
grep tcp /etc/services | grep daemon | grep -v service
```

- `tcp` 포함
- `daemon` 포함
- `service` 미포함

## 핵심 정리

- 표준 입력, 표준 출력, 표준 오류의 번호는 각각 `0`, `1`, `2`이다.
- `>`는 파일에 새로 기록하고, `>>`는 파일 끝에 내용을 추가한다.
- `<`는 파일을 표준 입력으로 사용하고, `2>`는 표준 오류를 파일로 보낸다.
- `2>&1`과 `&>`를 사용하면 표준 출력과 표준 오류를 같은 파일에 기록할 수 있다.
- `|`: 앞 명령어의 출력을 뒤 명령어의 입력으로 전달
- C 파이프는 [[Linux/개념/Linux 이름 있는 파이프 FIFO|이름 있는 파이프]], [[Linux/개념/Linux 프로세스 파이프|프로세스 파이프]], [[Linux/개념/Linux 이름 없는 파이프|이름 없는 파이프]]로 구분한다.
- FIFO와 이름 없는 파이프는 `read()`, `write()`를 사용하고, 프로세스 파이프는 `fread()`, `fwrite()`를 사용한다.
- `grep 패턴`: 패턴이 포함된 행 출력
- `grep -v 패턴`: 패턴이 포함되지 않은 행 출력
- `-i`, `-w`, `-c`: 대소문자 무시, 단어 단위 검색, 일치 행 개수 출력
- `-r`, `-n`: 하위 디렉터리 재귀 검색, 행 번호 표시
- 여러 파이프를 연결해 검색 조건을 단계적으로 적용할 수 있다.
