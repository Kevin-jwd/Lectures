# Linux glob 패턴

## glob이란

glob은 셸에서 파일이나 디렉터리 이름을 패턴으로 지정하는 기능이다. 명령어가 실행되기 전에 셸이 패턴과 일치하는 경로명으로 확장한다.

```bash
ls *.txt
```

현재 디렉터리에서 `.txt`로 끝나는 이름을 찾아 `ls`에 전달한다.

## 주요 glob 문자

| 패턴 | 의미 | 예시 |
|---|---|---|
| `*` | 문자가 없거나 여러 개 | `*.txt` |
| `?` | 임의의 문자 한 개 | `file?.txt` |
| `[abc]` | 대괄호 안의 문자 중 한 개 | `file[123].txt` |
| `[a-z]` | 지정한 범위의 문자 한 개 | `[a-z]*` |
| `[!abc]` | 대괄호 안의 문자가 아닌 한 개 | `[!0-9]*` |

## `*`

```bash
ls *.c
```

현재 디렉터리에서 `.c`로 끝나는 모든 이름과 일치한다.

```bash
ls file*
```

`file`로 시작하는 모든 이름과 일치한다.

## `?`

```bash
ls file?.txt
```

`file1.txt`, `fileA.txt`처럼 `file` 뒤에 정확히 한 문자가 있는 이름과 일치한다.

## `[]`

```bash
ls file[123].txt
```

`file1.txt`, `file2.txt`, `file3.txt`와 일치한다.

```bash
ls [a-z]*
```

영문 소문자로 시작하는 이름과 일치한다.

## 제외 패턴

```bash
ls [!0-9]*
```

숫자로 시작하지 않는 이름과 일치한다.

## glob과 정규표현식의 차이

glob과 정규표현식은 문법이 다르다.

| 목적 | glob | 정규표현식 |
|---|---|---|
| 모든 문자열 | `*` | `.*` |
| 임의의 문자 한 개 | `?` | `.` |

예를 들어 glob의 `*.txt`는 정규표현식으로는 대략 `.*\.txt`에 해당한다.

## 주의사항

- 패턴을 작은따옴표나 큰따옴표로 감싸면 셸의 glob 확장이 억제된다.
- 숨김 파일은 일반적으로 `*`만으로 선택되지 않는다.
- 명령어가 아니라 셸이 먼저 패턴을 실제 경로명으로 변환한다.
