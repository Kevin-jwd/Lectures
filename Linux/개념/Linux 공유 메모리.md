# Linux 공유 메모리

관련 개념: [[Linux/개념/Linux 프로세스|Linux 프로세스]], [[Linux/개념/Linux 세마포어|Linux 세마포어]]

## 개념

프로세스는 각각 **독립적인 가상 주소 공간**을 사용한다. 따라서 한 프로세스의 일반 변수를 다른 프로세스가 직접 읽거나 수정할 수 없다.

**공유 메모리(Shared Memory)**는 여러 프로세스가 함께 접근할 수 있는 메모리 영역을 제공하는 프로세스 간 통신 방식이다.

```text
프로세스 A의 가상 주소 공간 ─┐
                            ├─▶ 공유된 물리 메모리
프로세스 B의 가상 주소 공간 ─┘
```

> **중요:** 공유 메모리의 실제 데이터는 **물리 메모리**에 존재한다. 각 프로세스의 가상 주소 공간에 공유 메모리 세그먼트를 부착하면, 서로 다른 가상 주소를 통해 같은 물리 메모리에 접근할 수 있다.

## 공유 메모리 사용 흐름

```text
shmget()                 shmat()                         shmdt()
공유 메모리 생성·획득 → 가상 주소 공간에 세그먼트 부착 → 가상 주소 공간에서 분리
```

## `shmget()`

공유 메모리 세그먼트를 새로 만들거나 기존 세그먼트의 식별자 `shmid`를 얻는다.

```c
#include <sys/ipc.h>
#include <sys/shm.h>

int shmget(key_t key, size_t size, int shmflg);
```

| 인자 | 의미 |
|---|---|
| `key` | 공유 메모리를 구분하는 키 |
| `size` | 공유 메모리의 크기 |
| `shmflg` | 생성 옵션과 접근 권한 |

- 성공: 공유 메모리 식별자 `shmid` 반환
- 실패: `-1` 반환

## `shmat()`

공유 메모리 세그먼트를 호출한 프로세스의 **가상 주소 공간에 부착**한다.

```c
void *shmat(int shmid, const void *shmaddr, int shmflg);
```

| 인자 | 의미 |
|---|---|
| `shmid` | `shmget()`으로 얻은 공유 메모리 식별자 |
| `shmaddr` | 공유 메모리를 부착할 가상 주소 |
| `shmflg` | 부착 옵션 |

일반적으로 `shmaddr`에는 `NULL`을 전달한다.

```c
void *addr = shmat(shmid, NULL, 0);
```

프로그램이 프로세스의 가상 주소 공간에서 비어 있는 주소를 직접 찾는 것은 비효율적이다. `NULL`을 전달하면 커널이 사용 가능한 가상 주소를 선택하여 공유 메모리 세그먼트를 부착한다.

- 성공: 부착된 공유 메모리의 시작 주소 반환
- 실패: `(void *)-1` 반환

프로세스마다 반환되는 가상 주소는 다를 수 있지만, 연결되는 실제 물리 메모리는 같다.

## `shmdt()`

공유 메모리 세그먼트를 호출한 프로세스의 가상 주소 공간에서 분리한다.

```c
int shmdt(const void *shmaddr);
```

`shmaddr`에는 `shmat()`이 반환한 시작 주소를 전달한다.

- 성공: `0` 반환
- 실패: `-1` 반환
- `shmdt()`는 해당 프로세스에서 연결만 해제하며, 공유 메모리 세그먼트 자체를 삭제하는 함수는 아니다.

## 핵심 정리

- 프로세스는 독립적인 주소 공간을 사용하므로 일반 변수를 직접 공유할 수 없다.
- 공유 메모리는 여러 프로세스가 같은 **물리 메모리**를 공유하도록 한다.
- `shmget()`: 공유 메모리 생성 또는 식별자 획득
- `shmat()`: 공유 메모리를 프로세스의 가상 주소 공간에 부착
- `shmdt()`: 공유 메모리를 프로세스의 가상 주소 공간에서 분리
- `shmat(shmid, NULL, 0)`을 사용하면 커널이 부착할 가상 주소를 선택한다.
