# Linux 메시지 큐

관련 개념: [[Linux/개념/Linux 프로세스|Linux 프로세스]], [[Linux/개념/Linux 공유 메모리|Linux 공유 메모리]]

시험 요약: [[Linux/시험/메시지 큐 msgsnd와 msgrcv|메시지 큐 msgsnd와 msgrcv]]

## 개념

프로세스는 **유저 영역의 독립적인 가상 주소 공간**에서 실행되므로 일반 변수를 이용해 다른 프로세스와 직접 데이터를 주고받을 수 없다.

**메시지 큐(Message Queue)**는 커널 영역에 생성되는 메시지 저장 공간이다. 송신 프로세스가 커널의 메시지 큐에 데이터를 넣고, 수신 프로세스가 큐에서 데이터를 꺼내는 방식으로 통신한다.

```text
유저 영역                              커널 영역                              유저 영역
┌──────────────┐                 ┌──────────────────┐                 ┌──────────────┐
│ 송신 프로세스 │ ── msgsnd() ──▶ │    메시지 큐     │ ── msgrcv() ──▶ │ 수신 프로세스 │
└──────────────┘                 └──────────────────┘                 └──────────────┘
```

- 메시지 큐는 커널이 관리한다.
- 프로세스들은 메시지 큐 식별자 `msqid`를 이용해 같은 큐에 접근한다.
- 메시지는 **메시지 타입**과 **메시지 데이터**로 구성된다.

```c
struct msgbuf {
    long mtype;      // 메시지 타입: 0보다 큰 값
    char mtext[...]; // 실제 메시지 데이터
};
```

## 사용 흐름

```text
msgget() → msgsnd() / msgrcv() → msgctl()
큐 생성·획득    메시지 송수신       큐 제어·삭제
```

## `msgget()`

메시지 큐를 새로 만들거나 기존 메시지 큐의 식별자를 얻는다.

```c
#include <sys/types.h>
#include <sys/ipc.h>
#include <sys/msg.h>

int msgget(key_t key, int msgflg);
```

| 인자 | 의미 |
|---|---|
| `key` | 메시지 큐를 구분하는 키 |
| `msgflg` | 생성 옵션과 접근 권한 |

- 성공: 메시지 큐 식별자 `msqid` 반환
- 실패: `-1` 반환

## `msgsnd()`

유저 영역의 메시지를 커널 영역의 메시지 큐에 넣는다.

```c
int msgsnd(int msqid, const void *msgp, size_t msgsz, int msgflg);
```

| 인자 | 의미 |
|---|---|
| `msqid` | 메시지 큐 식별자 |
| `msgp` | 보낼 메시지 구조체의 주소 |
| `msgsz` | 메시지 데이터 `mtext`의 크기 |
| `msgflg` | 전송 동작 옵션 |

`msgsz`에는 `mtype`의 크기를 제외하고 실제 데이터인 `mtext`의 크기만 지정한다.

- 성공: `0` 반환
- 실패: `-1` 반환

## `msgrcv()`

커널 영역의 메시지 큐에서 메시지를 꺼내 유저 영역으로 가져온다.

```c
ssize_t msgrcv(int msqid, void *msgp, size_t msgsz,
               long msgtyp, int msgflg);
```

| 인자 | 의미 |
|---|---|
| `msqid` | 메시지 큐 식별자 |
| `msgp` | 메시지를 저장할 구조체의 주소 |
| `msgsz` | 받을 수 있는 `mtext`의 최대 크기 |
| `msgtyp` | 가져올 메시지 타입의 선택 조건 |
| `msgflg` | 수신 동작 옵션 |

- 성공: 수신한 메시지 데이터의 바이트 수 반환
- 실패: `-1` 반환

## `msgctl()`

메시지 큐의 상태를 조회·변경하거나 메시지 큐를 제거한다.

```c
int msgctl(int msqid, int cmd, struct msqid_ds *buf);
```

| 명령 | 의미 |
|---|---|
| `IPC_STAT` | 메시지 큐의 현재 상태 조회 |
| `IPC_SET` | 메시지 큐의 설정 변경 |
| `IPC_RMID` | 커널에서 메시지 큐 제거 |

- 성공: `0` 반환
- 실패: `-1` 반환

## 핵심 정리

- 프로세스는 유저 영역에서 실행되고 메시지 큐는 커널 영역에 존재한다.
- `msgget()`: 메시지 큐 생성 또는 식별자 획득
- `msgsnd()`: 메시지 큐에 메시지 전송
- `msgrcv()`: 메시지 큐에서 메시지 수신
- `msgctl()`: 메시지 큐 상태 제어 또는 제거
- 메시지 타입을 이용하면 수신할 메시지를 선택할 수 있다.
