# Linux Shell

## 개념

**Shell(셸)**은 사용자와 Linux 운영체제 사이에서 인터페이스 역할을 하는 프로그램이다. 사용자가 입력한 명령을 해석해 운영체제가 처리하도록 하고, 그 결과를 사용자에게 보여 준다.

```text
사용자 → Shell → 운영체제
사용자 ← 실행 결과 ← Shell
```

예를 들어 사용자가 현재 디렉터리를 확인하면 다음과 같은 흐름으로 처리된다.

```bash
pwd
```

```text
/home/aidl
```

1. 사용자가 Shell에 `pwd` 명령을 입력한다.
2. Shell이 명령을 해석하고 실행한다.
3. 실행 결과를 화면에 출력한다.

## Linux의 Shell 종류

Linux에는 여러 종류의 Shell이 있으며 각각 기능과 특징이 다르다.

| Shell | 특징 |
|---|---|
| `sh` | 전통적인 Unix 계열 Shell |
| `dash` | 기능이 단순하고 실행이 빠르며 시스템 Shell 스크립트에 적합 |
| `bash` | 기능이 풍부하고 사용자용 Shell로 널리 사용됨 |
| `ksh` | Korn Shell |
| `csh` | C 언어와 유사한 문법을 가진 Shell |

Linux에서는 `sh`가 별도의 Shell이 아니라 `dash` 등을 가리키는 [[Linux/개념/심볼릭 링크|심볼릭 링크]]로 구성되기도 한다. `dash`는 `bash`보다 기능은 적지만 가볍고 빠르므로 시스템용 Shell 스크립트 실행에 적합하다.

일반 사용자 Shell로는 `bash`가 널리 사용되므로 이후 명령과 예제는 기본적으로 `bash`를 기준으로 한다.



## 명령어 별칭

Shell에서는 자주 사용하는 긴 명령을 짧은 이름으로 등록하는 **별칭(alias)**을 사용할 수 있다.

```bash
alias
```

현재 등록된 별칭을 확인한다.

## Shell 스크립트

Shell은 명령을 직접 실행할 뿐 아니라, 명령을 파일에 작성한 **Shell 스크립트**도 실행할 수 있다. Shell 스크립트는 스크립트 언어로 작성되며 인터프리터가 소스를 한 줄씩 해석하여 실행한다.

### 컴파일 언어와 스크립트 언어

| 구분 | 컴파일 언어 | 스크립트 언어 |
|---|---|---|
| 예 | C, C++ | Shell 스크립트, Python |
| 실행 방식 | 소스를 기계어로 변환한 뒤 실행 | 인터프리터가 소스를 해석하며 실행 |
| 특징 | 실행 속도가 빠르지만 시스템 환경에 영향을 받을 수 있음 | 실행 속도는 상대적으로 느리지만 시스템 의존성이 낮음 |

## 핵심 정리

- Shell은 사용자 명령을 해석하여 운영체제와 연결하는 인터페이스이다.
- Linux에는 `sh`, `dash`, `bash`, `ksh`, `csh` 등 다양한 Shell이 있다.
- `dash`는 가볍고 빠르며, `bash`는 기능이 풍부해 사용자 Shell로 널리 쓰인다.
- `alias`를 사용하면 긴 명령에 짧은 별칭을 지정할 수 있다.
- Shell은 명령을 모아 작성한 Shell 스크립트를 실행할 수 있다.
