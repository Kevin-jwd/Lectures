# Linux 파일 접근 권한

Linux에서는 사용자에 따라 파일과 디렉터리에 접근할 수 있는 권한이 달라진다. 파일 정보에는 파일 종류, 접근 권한, 소유자와 소유 그룹이 함께 저장된다.

관련 개념: [[Linux/개념/Linux 사용자와 그룹|Linux 사용자와 그룹]]

## 권한 정보 확인

```bash
ls -l /var/log/syslog
```

출력 예시:

```text
-rw-r----- 1 syslog adm 1666130 Aug 5 11:30 /var/log/syslog
```

주요 필드는 다음과 같다.

| 구분 | 예시 | 의미 |
|---|---|---|
| 파일 종류 | `-` | 일반 파일, 디렉터리, 링크 등의 종류 |
| 접근 권한 | `rw-r-----` | 소유자·소유 그룹·기타 사용자의 권한 |
| 소유자 | `syslog` | 파일을 소유한 사용자 |
| 소유 그룹 | `adm` | 파일을 소유한 그룹 |

## 파일 종류

권한 문자열의 첫 번째 문자는 파일 종류를 나타낸다.

| 문자 | 파일 종류 |
|---|---|
| `-` | 일반 파일 |
| `d` | 디렉터리 |
| `l` | 심볼릭 링크 |
| `c` | 문자 장치 파일 |
| `b` | 블록 장치 파일 |
| `p` | 파이프 |
| `s` | 소켓 |

심볼릭 링크에 대한 자세한 내용은 [[심볼릭 링크|심볼릭 링크]]에서 확인할 수 있다.

## 접근 권한 구조

접근 권한은 총 9개의 문자로 표시된다.

```text
rwx rwx rwx
│   │   └─ 기타 사용자(other)
│   └───── 소유 그룹(group)
└───────── 소유자(user)
```

각 대상에 대해 읽기(`r`), 쓰기(`w`), 실행(`x`) 권한을 설정한다. 권한이 없으면 `-`로 표시한다.

## 파일 권한

| 문자 | 의미 |
|---|---|
| `r` | 파일 내용 읽기 |
| `w` | 파일 내용 수정 |
| `x` | 파일 실행 |
| `-` | 해당 권한 없음 |

## 디렉터리 권한

디렉터리에서는 같은 문자가 다른 동작을 의미한다.

| 문자 | 의미 |
|---|---|
| `r` | 디렉터리 안의 파일 목록 확인 |
| `w` | 디렉터리 안에 파일 생성·삭제·이름 변경 |
| `x` | 디렉터리에 진입하고 내부 항목에 접근 |
| `-` | 해당 권한 없음 |

> 디렉터리의 내용을 정상적으로 사용하려면 일반적으로 `x` 권한이 필요하다. `r` 또는 `w` 권한이 있어도 `x` 권한이 없으면 내부 파일 접근이 제한된다.

## 권한 해석 예시

```text
-rw-r-----
```

- `-`: 일반 파일
- `rw-`: 소유자는 읽기와 쓰기 가능
- `r--`: 소유 그룹은 읽기만 가능
- `---`: 기타 사용자는 접근 불가

### 사용자별 권한 적용 사례

다음과 같은 사용자와 그룹이 있다고 가정한다.

| 사용자 | 주 그룹 | 보조 그룹 |
|---|---|---|
| `jack` | `jack` | - |
| `anna` | `anna` | - |
| `paul` | `paul` | `anna` |
| `tom` | `tom` | - |

파일 정보는 다음과 같다.

```text
-rwxrw-r-- 1 jack anna 1234 Jan 19 12:25 myfile
```

| 사용자 | 적용되는 권한 | 읽기 | 쓰기 | 실행 |
|---|---|---|---|---|
| `jack` | 소유자 `rwx` | 가능 | 가능 | 가능 |
| `anna` | 그룹 `rw-` | 가능 | 가능 | 불가 |
| `paul` | 보조 그룹 `anna`의 `rw-` | 가능 | 가능 | 불가 |
| `tom` | 기타 사용자 `r--` | 가능 | 불가 | 불가 |

- `jack`: 파일 소유자이므로 소유자 권한 적용
- `anna`: 파일의 소유 그룹에 속하므로 그룹 권한 적용
- `paul`: 보조 그룹 `anna`에 속하므로 그룹 권한 적용
- `tom`: 소유자나 소유 그룹에 해당하지 않으므로 기타 사용자 권한 적용

## 접근 권한 변경: `chmod`

`chmod`는 파일이나 디렉터리의 접근 권한을 변경한다. 일반적으로 파일 소유자 또는 `root`가 사용할 수 있다.

### 8진수 모드

각 권한에 숫자를 부여하고 합산한다.

| 권한 | 숫자 |
|---|---:|
| 읽기 `r` | 4 |
| 쓰기 `w` | 2 |
| 실행 `x` | 1 |

숫자는 차례대로 소유자, 소유 그룹, 기타 사용자의 권한을 나타낸다.

각 숫자는 `rwx`를 3비트로 나타낸 값과 같다.

| 8진수 | 2진수 | 권한 |
|---:|---:|---|
| 0 | `000` | `---` |
| 1 | `001` | `--x` |
| 2 | `010` | `-w-` |
| 3 | `011` | `-wx` |
| 4 | `100` | `r--` |
| 5 | `101` | `r-x` |
| 6 | `110` | `rw-` |
| 7 | `111` | `rwx` |

```bash
sudo chmod 764 hello.c
```

```text
7 = 111 = rwx
6 = 110 = rw-
4 = 100 = r--
```

따라서 `hello.c`의 권한은 `rwxrw-r--`가 된다.

### 기호 모드

기호를 사용하여 특정 대상의 권한만 선택적으로 변경한다.

| 기호 | 의미 |
|---|---|
| `u` | 소유자(user) |
| `g` | 소유 그룹(group) |
| `o` | 기타 사용자(other) |
| `a` | 모든 사용자(all) |
| `+` | 권한 추가 |
| `-` | 권한 제거 |
| `=` | 권한을 지정한 값으로 설정 |

```bash
sudo chmod a-x hello.c
```

모든 사용자에게서 실행 권한을 제거한다. 기존 권한이 `rwxrwxr-x`였다면 `rw-rw-r--`로 변경된다.

```text
a-x
│ └─ 실행 권한 제거
└─── 모든 사용자
```

## `sudo`의 의미

```bash
sudo 명령어
```

`sudo`는 허가된 일반 사용자가 명령 하나를 관리자 권한으로 실행하게 한다. 슬라이드의 명령에 `sudo`가 붙은 이유는 다른 사용자가 소유한 파일의 권한·소유자·소유 그룹을 변경하려면 관리자 권한이 필요할 수 있기 때문이다.

> 자신이 소유한 파일의 권한을 바꾸는 `chmod`는 일반적으로 `sudo` 없이 실행할 수 있다. `chown`을 통한 소유자 변경은 일반적으로 관리자 권한이 필요하다.

## 소유자와 소유 그룹 변경: `chown`

`chown`은 파일이나 디렉터리의 소유자 또는 소유 그룹을 변경한다. 소유자 변경에는 일반적으로 `root` 권한이 필요하다.

### 소유자만 변경

```bash
sudo chown root hello.c
```

`hello.c`의 소유자를 `root`로 변경한다.

### 소유자와 소유 그룹 함께 변경

```bash
sudo chown aidl:root hello.c
```

- 소유자: `aidl`
- 소유 그룹: `root`

## 소유 그룹 변경: `chgrp`

`chgrp`는 파일이나 디렉터리의 소유 그룹만 변경한다.

```bash
sudo chgrp aidl hello.c
```

`hello.c`의 소유 그룹을 `aidl`로 변경한다.

## 명령어 비교

| 명령어 | 변경 대상 |
|---|---|
| `chmod` | 접근 권한 |
| `chown` | 소유자 또는 소유 그룹 |
| `chgrp` | 소유 그룹 |

## 핵심 정리

- 첫 번째 문자는 파일 종류를 나타낸다.
- 다음 9개 문자는 소유자, 소유 그룹, 기타 사용자의 권한을 나타낸다.
- 파일과 디렉터리에서 `r`, `w`, `x`의 의미가 다르다.
- 디렉터리 내부에 접근하려면 `x` 권한이 중요하다.
- `chmod`는 권한, `chown`은 소유자, `chgrp`는 소유 그룹을 변경한다.
