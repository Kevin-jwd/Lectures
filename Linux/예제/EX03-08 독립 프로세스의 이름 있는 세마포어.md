# EX03-08 독립 프로세스의 이름 있는 세마포어

관련 개념: [[Linux/개념/Linux 세마포어|Linux 세마포어]], [[Linux/개념/Linux 프로세스|Linux 프로세스]]

## 문제 상황

서로 독립적으로 실행한 여러 `rw` 프로세스가 같은 `test.txt`에 접근한다. 모든 `rw`가 **동일한 세마포어**로 파일 접근을 제어해야 한다.

## 이름 없는 세마포어가 동작하지 않은 이유

기존 방식은 이름 없는 세마포어를 전역 변수로 선언했다.

```c
sem_t noname_sem;
sem_init(&noname_sem, 0, 1);
```

두 번째 인자인 `pshared=0`은 **같은 프로세스의 스레드 간 공유**를 뜻한다. `rw`를 별도로 두 번 실행하면 프로세스마다 독립된 주소 공간과 `noname_sem`이 생긴다.

```text
./rw 프로세스 A → A의 noname_sem ─┐
                                 ├─ 서로 다른 세마포어 → test.txt 접근을 함께 제어하지 못함
./rw 프로세스 B → B의 noname_sem ─┘
```

## 이름 있는 POSIX 세마포어로 변경

```c
sem_open("/ex03_08_rw_sem", O_CREAT, 0666, 1);
```

별도로 실행한 `rw`들이 **같은 이름**으로 `sem_open()`하면 같은 세마포어를 연다. 각 프로세스는 이 세마포어에 `sem_wait()`과 `sem_post()`를 수행하여 `test.txt` 접근을 조정한다.

```text
./rw 프로세스 A ─┐
                 ├─ "/ex03_08_rw_sem" → 같은 세마포어 → test.txt
./rw 프로세스 B ─┘
```

## 핵심 포인트

- 이름 없는 세마포어도 프로세스 간에 사용할 수 있다. 이때 `sem_t`를 **공유 메모리**에 두고 `sem_init(..., 1, 1)`처럼 `pshared`를 `0`이 아닌 값으로 설정해야 한다.
- 이 예제는 독립 프로세스가 같은 이름으로 열 수 있는 **이름 있는 세마포어**를 선택해 구조를 단순하게 했다.
- `sem_init()`·`sem_open()`은 POSIX 세마포어 API이며, `semget()`·`semop()`·`semctl()`을 쓰는 System V 방식과 구분한다.
