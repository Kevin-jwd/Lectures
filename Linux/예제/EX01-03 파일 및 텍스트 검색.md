# EX01-03 파일 및 텍스트 검색

관련 개념: [[Linux/개념/Linux 파이프와 grep|Linux 파이프와 grep]]

## 문제 1

`/etc` 디렉터리에서 하위 디렉터리를 제외하고 접근 권한이 `755`인 디렉터리를 모두 출력한다.

```bash
find /etc -maxdepth 1 -type d -perm 0755
```

- `/etc`: 검색 시작 경로
- `-maxdepth 1`: `/etc` 바로 아래까지만 검색
- `-type d`: 디렉터리만 선택
- `-perm 0755`: 권한이 정확히 `755`인 항목만 선택

## 문제 2

`/etc` 디렉터리에서 하위 디렉터리를 제외하고 파일명에 `bash`와 `comp`가 모두 포함된 파일 또는 디렉터리를 출력한다.

```bash
find /etc -maxdepth 1 -name '*bash*' -name '*comp*'
```

두 `-name` 조건을 함께 사용하므로 이름에 `bash`와 `comp`가 모두 포함되어야 한다.

## 문제 3

`/etc/services`에서 `tcp`와 `daemon`을 포함하지만 `service`는 포함하지 않는 행을 모두 출력한다.

```bash
grep tcp /etc/services | grep daemon | grep -v service
```

1. `tcp`가 포함된 행 선택
2. 결과 중 `daemon`도 포함된 행 선택
3. 결과 중 `service`가 포함된 행 제외

## 문제 4

저장된 커널 메시지를 출력하는 `dmesg`의 결과에서 `enabled`가 포함된 행을 모두 출력한다.

```bash
dmesg | grep enabled
```

일반 사용자에게 커널 로그 접근 권한이 없다면 다음과 같이 실행한다.

```bash
sudo dmesg | grep enabled
```
