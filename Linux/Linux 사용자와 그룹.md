# Linux 사용자와 그룹

## 다중 사용자 운영체제

Linux는 여러 사용자가 동시에 시스템에 접근할 수 있는 **다중 사용자 운영체제**이다.

사용자는 역할에 따라 다음과 같이 구분된다.

- **관리자 사용자**: 시스템의 모든 권한을 가진 `root`
- **시스템 사용자**: 특정 서비스나 기능을 실행하기 위한 사용자
- **일반 사용자**: 사람이 로그인하여 시스템을 사용하는 계정

## root 사용자

`root`는 Linux 시스템의 관리자 계정이다.

- UID가 `0`이다.
- 시스템의 모든 파일과 명령에 접근할 수 있다.
- 시스템 설정 변경, 사용자 관리 등 모든 관리 작업을 수행할 수 있다.
- 강력한 권한을 가지므로 명령 실행 시 주의해야 한다.

## 시스템 사용자

시스템 사용자는 웹 서버, 데이터베이스 등 특정 서비스나 기능을 실행하기 위해 생성되는 계정이다.

- 일반적으로 직접 로그인하지 않는다.
- 홈 디렉터리가 없거나 로그인 셸이 `/usr/sbin/nologin` 등으로 설정된다.
- 필요한 최소한의 권한만 부여하여 서비스의 피해 범위를 제한한다.

## 일반 사용자

일반 사용자는 시스템에 로그인하여 파일을 생성하거나 프로그램을 실행하는 계정이다.

- 고유한 UID를 가진다.
- 개인 홈 디렉터리를 사용한다.
- 관리자 작업이 필요하면 권한 설정에 따라 `sudo`를 사용한다.

## 사용자 정보 파일: `/etc/passwd`

Linux의 사용자 목록과 기본 계정 정보는 `/etc/passwd`에 저장된다.

```text
root:x:0:0:root:/root:/bin/bash
```

각 필드는 콜론(`:`)으로 구분된다.

```text
사용자 이름:암호 표시:UID:GID:설명:홈 디렉터리:로그인 셸
```

| 필드 | 예시 | 의미 |
|---|---|---|
| 사용자 이름 | `root` | 로그인할 때 사용하는 계정 이름 |
| 암호 표시 | `x` | 실제 암호 정보가 `/etc/shadow`에 있음을 의미 |
| UID | `0` | 사용자의 고유 번호 |
| GID | `0` | 사용자의 주 그룹 번호 |
| 설명 | `root` | 사용자에 대한 부가 정보 |
| 홈 디렉터리 | `/root` | 로그인 후 기본 작업 디렉터리 |
| 로그인 셸 | `/bin/bash` | 로그인할 때 실행되는 셸 |

> `/etc/passwd`의 두 번째 필드가 `x`라면 암호화된 실제 암호는 `/etc/shadow`에 저장된다.

## UID

UID(User ID)는 사용자를 구분하는 고유 번호이다.

- `0`: 관리자 `root`
- `1~999`: 주로 시스템 사용자
- `1000` 이상: 주로 일반 사용자

UID 범위는 Linux 배포판과 시스템 설정에 따라 다를 수 있다.

## GID와 그룹

GID(Group ID)는 사용자가 속한 그룹의 고유 번호이다.

- 모든 사용자는 하나의 **주 그룹**에 속한다.
- 필요하면 여러 **보조 그룹**에도 속할 수 있다.
- 사용자가 생성한 파일은 일반적으로 사용자의 주 그룹을 소유 그룹으로 사용한다.
- 그룹을 이용하면 여러 사용자에게 파일 접근 권한을 함께 부여할 수 있다.

## 핵심 정리

- Linux는 여러 사용자가 동시에 사용할 수 있다.
- `root`는 UID `0`을 가진 관리자이다.
- 시스템 사용자는 주로 서비스 실행에 사용되며 로그인이 제한된다.
- 사용자 기본 정보는 `/etc/passwd`에 저장된다.
- 실제 암호 정보는 `/etc/shadow`에 저장된다.
- UID는 사용자, GID는 그룹을 식별한다.
