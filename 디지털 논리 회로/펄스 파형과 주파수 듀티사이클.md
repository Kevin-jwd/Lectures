# 펄스 파형과 주파수·듀티사이클

출처: 자료 I, 14~19쪽 · [[디지털 논리 회로/00 디지털 논리 회로 길잡이|길잡이]]

## 펄스와 에지

펄스는 [[디지털 논리 회로/논리 레벨과 정논리 부논리|Low와 High]]가 시간에 따라 바뀌는 전압 파형이다.

- **주기 펄스**: 일정한 시간 간격으로 반복.
- **비주기 펄스**: 간격이 일정하지 않거나 한 번 발생. 데이터 신호·트리거 등이 예이다.
- **상승 에지**: Low → High.
- **하강 에지**: High → Low.

자료의 Verilog 표기:

```verilog
always @(posedge clk)  // 상승 에지
always @(negedge clk)  // 하강 에지
```

클록 기반 [[디지털 논리 회로/조합논리와 순차논리|순차회로]]는 특정 에지를 기준으로 상태를 갱신한다.

## 실제 파형의 시간

| 항목 | 의미 |
|---|---|
| 상승 시간 tr | 낮은 전압에서 높은 전압으로 올라가는 시간 |
| 하강 시간 tf | 높은 전압에서 낮은 전압으로 내려가는 시간 |
| 펄스폭 tw | 펄스가 High로 유지되는 시간 |

자료에서는 상승·하강 시간을 보통 전압의 10~90% 구간 등으로 측정한다고 설명한다. 상승·하강 시간이 길면 고속 회로의 타이밍 여유가 줄어들 수 있다. **입력과 출력 사이의 지연**은 [[디지털 논리 회로/전파 지연과 전력 소모]]에서 다룬다.

## 주기와 주파수

$$f=\frac{1}{T},\qquad T=\frac{1}{f}$$

- T: 한 번 반복되는 시간, 단위 s.
- f: 1초의 반복 횟수, 단위 Hz.
- ms = 10⁻³s, μs = 10⁻⁶s, ns = 10⁻⁹s.

| 조건 | 결과 |
|---|---|
| T = 10ms | f = 100Hz |
| f = 50MHz | T = 20ns |
| f = 100MHz | T = 10ns |

## 듀티사이클

$$D(\%)=\frac{t_{HIGH}}{T}\times100$$

듀티는 한 주기 중 **High가 차지하는 비율**이다. PWM에서는 이를 바꿔 LED 밝기나 모터 속도 등에 영향을 줄 수 있다.

자료 예제: 펄스폭 50μs, 주기 250μs이면 **4kHz, 듀티 20%**이다.

```text
f = 1 / (250 × 10⁻⁶) = 4,000Hz
D = 50 / 250 × 100 = 20%
```

250Hz(T=4ms) 파형의 High 시간은 듀티 25%에서 1ms, 50%에서 2ms, 75%에서 3ms이다. **주파수는 반복 속도**, **듀티는 High 비율**을 결정한다.
