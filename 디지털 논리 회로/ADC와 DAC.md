# ADC와 DAC

출처: 자료 I, 6·25~28쪽 · [[디지털 논리 회로/00 디지털 논리 회로 길잡이|길잡이]]

## 변환 방향

- **ADC**: Analog-to-Digital Converter. 아날로그 신호를 디지털 코드로 변환.
- **DAC**: Digital-to-Analog Converter. 디지털 코드에 대응하는 아날로그 전압·전류 생성.

[[디지털 논리 회로/아날로그와 디지털 시스템|현실의 연속 신호와 디지털 처리]]를 연결하는 장치이다.

## ADC의 세 단계

```text
아날로그 신호 → 표본화 → 양자화 → 부호화 → 디지털 신호
```

| 단계 | 하는 일 | 핵심 |
|---|---|---|
| 표본화(sampling) | 일정한 시간 간격으로 값을 측정 | 시간축에서 샘플 선택 |
| 양자화(quantization) | 측정된 진폭을 정해진 레벨로 바꿈 | 양자화 잡음 발생 |
| 부호화(coding) | 양자화된 값을 2진 코드로 표현 | 비트열로 전달·저장 |

자료의 표본화 정리는 **신호 최고 주파수의 2배 이상 빈도로 샘플링**하면 원래 정보를 재현할 수 있다고 설명한다. 예시는 음성 최고 주파수 4kHz에 대해 8kHz 표본화이다. 빈도와 간격 관계는 [[디지털 논리 회로/펄스 파형과 주파수 듀티사이클]]과 같다.

레벨 수를 늘리면 양자화 잡음을 줄일 수 있지만 데이터 양이 많아진다. [[디지털 논리 회로/디지털 정보와 데이터 단위|4bit]]는 16가지 코드를 표현한다.

자료의 변환 예:

```text
표본값:   2.8   13.8   7.0   3.3   9.3   8.3   5.5   4.8
양자화:     3     14     7     3     9     8     6     5
부호화:  0011   1110  0111  0011  1001  1000  0110  0101
```

## DAC 계산 예제

8bit DAC에서 입력 00110010₂(50)에 대해 1.0V가 출력되었다. 자료는 입력 코드에 비례하는 관계로 최대 코드 11111111₂(255)의 출력을 계산한다.

```text
50 : 1.0V = 255 : 최대 출력
최대 출력 = 1.0 × 255 / 50 = 5.1V
```

## 자료의 CD 오디오 흐름

```text
소리 → 마이크 → 앰프 → ADC → CD 저장 → DAC → 앰프 → 스피커 → 소리
```
