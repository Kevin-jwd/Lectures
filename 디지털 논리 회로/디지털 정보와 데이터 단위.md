# 디지털 정보와 데이터 단위

출처: 자료 I, 8~10쪽 · [[디지털 논리 회로/00 디지털 논리 회로 길잡이|길잡이]]

## 기본 단위

| 단위 | 의미 |
|---|---|
| bit | 0 또는 1 하나를 저장하는 최소 단위 |
| nibble | 4bit, 16가지 상태 |
| byte | 8bit, 256가지 조합 |
| word | 프로세서가 기본적으로 처리하는 길이. 시스템에 따라 16·32·64bit 등 |

[[디지털 논리 회로/논리 레벨과 정논리 부논리|논리 0과 1]]을 여러 비트로 조합해 정보를 표현한다. [[디지털 논리 회로/ADC와 DAC|ADC/DAC]]에서도 비트 수가 표현 가능한 코드 수를 결정한다.

## MSB와 LSB

- **MSB**: 가장 높은 자리의 비트(Most Significant Bit).
- **LSB**: 가장 낮은 자리의 비트(Least Significant Bit).

```text
10110010
↑      ↑
MSB    LSB
 1      0
```

## 10진 단위와 2진 단위

| 크기 | 10진 단위 | 2진 단위 |
|---|---|---|
| 천 단위 | k = 10³ | Ki = 2¹⁰ |
| 백만 단위 | M = 10⁶ | Mi = 2²⁰ |
| 십억 단위 | G = 10⁹ | Gi = 2³⁰ |
| 조 단위 | T = 10¹² | Ti = 2⁴⁰ |

**1 GB = 1,000,000,000 byte**, **1 GiB = 1,073,741,824 byte**이다. 단위 변환에서는 bit/byte와 10진/2진 구분을 동시에 확인한다.

## 자료의 계산 예제

```text
9.6 GiB → bit
= 9.6 × 2³⁰ × 8
≈ 82,463,372,083 bit

32 GB → GiB
= 32,000,000,000 / 2³⁰
≈ 29.80 GiB
```
