# 조합논리와 순차논리

출처: 자료 I, 21쪽 · [[디지털 논리 회로/00 디지털 논리 회로 길잡이|길잡이]]

## 핵심 차이

| 구분 | 조합논리 | 순차논리 |
|---|---|---|
| 출력 결정 | 현재 입력 | 현재 입력과 이전 상태 |
| 기억 | 없음 | 상태를 저장함 |
| 구성 | 논리 게이트의 결합 | 조합논리와 플립플롭·메모리 |
| 자료의 예 | AND, OR, NOT, NAND, NOR, XOR, 멀티플렉서, 디코더, 가산기 | 플립플롭, 레지스터, 카운터, FSM, 메모리 |

**같은 입력이어도 저장된 상태가 다르면 동작이 달라질 수 있는 것이 순차논리의 특징**이다. 자료는 Verilog에서 조합논리와 클록 기반 순차논리를 구분해 설계하는 것이 중요하다고 설명한다.

```text
조합논리: 입력 → 논리회로 → 출력
순차논리: 현재 입력 + 저장된 상태 → 논리회로 → 출력·다음 상태
```

관련 게이트: [[디지털 논리 회로/NOT과 버퍼]], [[디지털 논리 회로/AND OR NAND NOR]], [[디지털 논리 회로/XOR과 XNOR]]. 클록과 상태 갱신의 기준은 [[디지털 논리 회로/펄스 파형과 주파수 듀티사이클|에지]]에서 확인한다.

## 플립플롭과 래치

아래는 요청에 따라 추가한 보충 설명이다. **둘 다 1비트의 상태를 저장하는 소자**이며, 여러 개를 묶어 여러 비트의 값을 저장할 수 있다. 핵심 차이는 **입력 값을 언제 받아들이는가**이다.

| 구분 | 플립플롭(Flip-flop) | 래치(Latch) |
|---|---|---|
| 반응 기준 | 클록의 **에지** | 제어 신호의 **레벨** |
| 입력 반영 | 상승 또는 하강 에지에서 입력을 저장 | 활성 레벨인 동안 입력 변화가 출력에 반영 |
| 값 유지 | 다음 유효 에지까지 저장값 유지 | 제어 신호가 비활성이면 저장값 유지 |
| 대표 예 | D 플립플롭 | D 래치 |

### D 플립플롭: 순간을 기준으로 저장

상승 에지형 D 플립플롭은 클록이 **0 → 1로 바뀌는 순간**의 입력 D를 저장하여 출력 Q로 내보낸다. 에지 사이에 D가 바뀌어도 Q는 저장한 값을 유지한다.

- 클록이 계속 1인 동안 D가 바뀐다고 Q가 따라 바뀌지는 않는다.
- 다음 상승 에지에서 새로운 D를 저장한다.
- 하강 에지형은 1 → 0인 순간을 기준으로 동작한다.

### D 래치: 열려 있는 동안 입력을 통과

활성 High D 래치는 **Enable이 1인 동안 Q가 D를 따라가고**, Enable이 0이 되면 마지막 값을 저장하여 유지한다. 입력이 통과하는 구간을 **투명(Transparent) 상태**라고 한다.

- Enable이 1인 동안에는 D가 여러 번 바뀌면 Q도 그 변화를 따라간다.
- Enable이 0이면 D가 바뀌어도 Q는 유지된다.
- 활성 Low 래치는 반대로 제어 신호가 0일 때 열린다.

**플립플롭은 특정 순간에 찍는 사진, 래치는 열려 있는 동안 보이다가 닫으면 마지막 모습이 남는 창**으로 기억한다.

위 설명은 리셋 등의 별도 제어를 제외한 기본 동작이다. 실제 소자는 입력이 저장 시점 전후로 안정되어 있어야 하며 출력에도 전파 지연이 있다.

### Verilog에서 연결해서 이해하기

- 클록 에지를 조건으로 상태를 갱신하는 코드는 플립플롭 동작과 연결된다.
- 조합논리로 작성하려던 절차 블록에서 일부 조건의 출력 할당을 빠뜨리면, **이전 값을 유지해야 하므로 의도하지 않은 래치가 추론될 수 있다.**
- 따라서 조합논리에서는 모든 조건에서 출력값이 정해지도록 작성한다.

에지와 레벨의 기준은 [[디지털 논리 회로/펄스 파형과 주파수 듀티사이클]], 클록 기반 Verilog 예제는 [[Vivado/Verilog 모듈과 게이트 회로]]에서 확인한다.
