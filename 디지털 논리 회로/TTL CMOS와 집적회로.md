# TTL·CMOS와 집적회로

출처: 자료 I, 22~23쪽 / 자료 II, 41·55~57쪽 · [[디지털 논리 회로/00 디지털 논리 회로 길잡이|길잡이]]

## IC 계열

| 구분 | TTL | CMOS |
|---|---|---|
| 이름 | Transistor-Transistor Logic | Complementary Metal Oxide Semiconductor |
| 구성 | BJT와 다이오드 | NMOS와 PMOS FET |
| 자료의 대표 계열 | 74LS, 74ALS, 74F, 74AS | 4000B, 74HC |
| 자료가 강조하는 특징 | 짧은 전파 지연, 비교적 큰 전력 소모 | 적은 전력 소모, 넓은 사용 전압 범위, 집적화 용이 |

자료는 종래 CMOS와 고속 CMOS를 구분하며 고속 CMOS의 보급을 소개한다. 속도와 전력은 [[디지털 논리 회로/전파 지연과 전력 소모]], 전압의 차이는 [[디지털 논리 회로/논리 레벨과 정논리 부논리]]에서 연결해 읽는다.

자료의 사용 온도 범위: **74계열 0~70℃**, **54계열 −55~125℃**.

## 특성표에서 읽을 항목

- tPLH·tPHL: 전파 지연.
- VOH·VOL·VIH·VIL: 출력·입력 전압. [[디지털 논리 회로/잡음 여유도]] 계산에 사용.
- IOH·IOL·IIH·IIL: 출력·입력 전류. [[디지털 논리 회로/팬인 팬아웃과 싱크 소스 전류|팬아웃]] 계산에 사용.

## 부품명 읽기

자료의 구분 순서는 **제조사 → 시리즈 → 회로 타입 → 기능 번호 → 패키지**이다.

```text
MC 74 F 00 N
│  │  │ │  └─ Plastic DIP 패키지
│  │  │ └──── 기능 번호
│  │  └────── Fast 타입
│  └───────── 시리즈
└──────────── 제조사
```

| 타입 | 자료의 의미 |
|---|---|
| LS | Low Power Schottky |
| F | Fast |
| HC | High Speed CMOS |
| HCT | High Speed CMOS, LS TTL 호환 |
| ALS | Advanced Low Power Schottky |

자료에 등장하는 기능 번호 예: 7404 NOT, 7407 버퍼, 7408 AND, 7432 OR, 7400 NAND, 7402 NOR, 7486 XOR. 동작은 [[디지털 논리 회로/NOT과 버퍼]], [[디지털 논리 회로/AND OR NAND NOR]], [[디지털 논리 회로/XOR과 XNOR]]에서 확인한다.

## 패키지와 집적도

- **DIP**: 삽입 장착. PCB 구멍에 핀을 넣고 납땜한다.
- **SMD**: 표면 실장. PCB 표면에 장착한다. 자료의 형태 예는 SOIC·QFP·PLCC이다.

집적도는 한 칩 안에 들어가는 소자 수와 관련된다. 자료의 대략적 분류:

| 분류 | 소자 수 |
|---|---|
| SSI | 약 100개 이하 |
| MSI | 약 100~1,000개 |
| LSI | 약 1,000~10,000개 |
| VLSI | 약 10,000~1,000,000개 |
| ULSI | 약 1,000,000개 이상 |

자료는 FPGA·CPU·SoC가 높은 집적도를 통해 많은 기능을 통합하며, 전원·열·배선·검증도 중요해진다고 설명한다.
