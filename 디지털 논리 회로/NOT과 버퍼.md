# NOT과 버퍼

출처: 자료 II, 3~9쪽 · [[디지털 논리 회로/00 디지털 논리 회로 길잡이|길잡이]]

## NOT과 일반 버퍼

| A | NOT 출력 | 버퍼 출력 |
|---|---|---|
| 0 | 1 | 0 |
| 1 | 0 | 1 |

- **NOT**: 입력을 반전. 논리식 F = A′.
- **버퍼**: 입력 그대로 전달. 논리식 F = A.

자료의 NOT 두 개 직렬 연결 예제에서는 첫 출력 X = A′, 다음 출력 Y = X′이므로 **최종 출력은 입력과 같은 파형**이다. 버블 기호는 [[디지털 논리 회로/논리 레벨과 정논리 부논리]]에서 확인한다.

## 3상태 버퍼

출력 상태가 **0, 1, Hi-Z** 세 가지이다. **Hi-Z(하이 임피던스)**는 자료에서 입력과 출력이 연결되지 않은 상태로 설명한다.

| 제어 방식 | 전달 조건 | 나머지 조건 |
|---|---|---|
| Low에서 활성(74125) | 제어 입력 0이면 F = A | 제어 입력 1이면 Hi-Z |
| High에서 활성(74126) | 제어 입력 1이면 F = A | 제어 입력 0이면 Hi-Z |

자료의 파형 문제는 먼저 **제어 단자의 활성 구간**을 찾은 뒤, 그 구간에서 입력 파형을 출력으로 전달한다. 비활성 구간은 0이 아니라 Hi-Z로 표시한다.

## 3상태 인버터 예제

자료의 제어 S가 High일 때 활성인 인버터:

| A | S | F |
|---|---|---|
| 0 | 0 | Hi-Z |
| 1 | 0 | Hi-Z |
| 0 | 1 | 1 |
| 1 | 1 | 0 |

버퍼의 실제 구동 능력은 [[디지털 논리 회로/팬인 팬아웃과 싱크 소스 전류]]와 연결되며, 입력 레벨을 확정하는 방법은 [[디지털 논리 회로/풀업과 풀다운 저항]]에서 다룬다.
