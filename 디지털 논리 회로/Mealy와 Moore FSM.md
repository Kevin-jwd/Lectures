# Mealy와 Moore FSM

## FSM의 기본 구조

**FSM(Finite State Machine, 유한 상태 머신)은 유한한 상태를 가지고 입력 조건에 따라 상태를 바꾸는 회로**이다. 현재 상태를 기억하므로 [[디지털 논리 회로/조합논리와 순차논리|순차논리 회로]]에 해당한다.

- **현재 상태(state)**: 지금 어떤 단계인지 저장한 값.
- **다음 상태(next_state)**: 현재 상태와 입력으로 결정한 다음 단계.
- **상태 레지스터**: 클록 에지에서 다음 상태를 현재 상태로 저장.
- **출력 논리**: 현재 상태 또는 현재 상태와 입력으로 출력을 결정.

두 방식 모두 다음 상태는 **현재 상태와 입력**에 따라 결정한다. 구분 기준은 **출력을 결정할 때 입력도 직접 사용하는가**이다.

## 핵심 비교

| 구분 | Mealy FSM | Moore FSM |
|---|---|---|
| 출력 결정 | **현재 상태 + 현재 입력** | **현재 상태만** |
| 상태가 그대로일 때 | 입력 변화로 출력이 바뀔 수 있음 | 입력만 바뀌어서는 출력이 바뀌지 않음 |
| 기본 출력 반응 | 클록 사이에도 입력 변화에 반응 가능 | 상태가 갱신된 후 출력 변화 |
| 상태도 출력 표기 | 전이 화살표에 `입력 / 출력` | 상태 원 안에 `상태 / 출력` |
| 상태 수 | 같은 기능에서 더 적은 상태로 표현 가능한 경우가 있음 | 출력을 구분할 상태가 더 필요할 수 있음 |
| 주의점 | 입력 변화·글리치가 출력에 직접 영향을 줄 수 있음 | 상태 디코딩 과정에서도 글리치 가능, 무조건 글리치가 없는 것은 아님 |

**Mealy는 상태와 입력을 보고 출력, Moore는 상태를 보고 출력**으로 기억한다.

## 같은 입력에 대한 반응 예

대기 상태 WAIT에서 요청 req가 들어오면 처리 상태 DONE으로 이동하고, 요청을 알리는 출력을 만든다고 생각한다. 아래는 출력 레지스터를 별도로 두지 않은 기본 구조의 비교이다.

### Mealy

```verilog
assign out = (state == WAIT) & req;
```

WAIT에 있는 동안 req가 1이 되면 **다음 클록을 기다리지 않고**, 조합논리의 전파 지연 후 out이 1이 된다. 다음 클록에 DONE으로 이동하면 WAIT 조건이 사라져 out은 0이 된다.

### Moore

```verilog
assign out = (state == DONE);
```

WAIT에서 req가 1이 되어도 out은 아직 0이다. **다음 클록 에지에서 DONE으로 이동한 뒤** out이 1이 된다. DONE에 머무르는 동안에는 req가 바뀌어도 out은 1을 유지한다.

두 예시는 요청에 반응하는 시점의 차이를 보여주며, 동일한 폭의 출력 펄스를 보장하는 완성 회로는 아니다. DONE에서 나가는 조건에 따라서도 출력 유지 시간이 달라진다.

## Verilog로 구현할 때

FSM은 다음 세 부분으로 나누어 읽으면 쉽다.

| 부분 | 대표 작성 방식 | 역할 |
|---|---|---|
| 상태 저장 | `always @(posedge clk)`와 `<=` | 클록에 맞춰 state 갱신 |
| 다음 상태 결정 | `always @(*)`, `case`, `if` | state와 입력으로 next_state 계산 |
| 출력 결정 | `assign` 또는 `always @(*)` | Mealy는 state·입력, Moore는 state로 출력 계산 |

- **`assign`을 썼는지 `always`를 썼는지로 Mealy·Moore를 구분하지 않는다.** 출력이 무엇에 의존하는지를 본다.
- 조합논리 블록에서는 기본값을 주거나 모든 조건을 처리하여 의도하지 않은 래치를 막는다.
- 리셋 시 시작 상태를 정하고, 상태 레지스터는 논블로킹 할당으로 갱신한다.
- Mealy 출력에 별도 레지스터를 붙이는 등의 변형도 있으므로, **Mealy는 항상 즉시 출력, Moore는 항상 정확히 한 클록 느림**이라고 단정하지 않는다. 위 비교는 기본 구조 기준이다.

문법과 할당 방식은 [[Vivado/Verilog 모듈과 게이트 회로]], 저장 소자는 [[디지털 논리 회로/조합논리와 순차논리#플립플롭과 래치|플립플롭과 래치]]를 참고한다.

## 테스트할 때 확인할 것

- 리셋 후 시작 상태가 맞는가?
- 입력 조건마다 다음 클록에서 예상한 상태로 이동하는가?
- **클록 사이에 입력을 바꿨을 때 출력이 달라지는가?**
- 출력이 발생하는 상태·입력 조건과 유지 시간이 맞는가?
