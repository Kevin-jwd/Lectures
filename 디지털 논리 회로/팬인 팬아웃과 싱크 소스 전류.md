# 팬인·팬아웃과 싱크·소스 전류

출처: 자료 II, 41·49~52쪽 · [[디지털 논리 회로/00 디지털 논리 회로 길잡이|길잡이]]

## 연결 수

- **팬인(fan-in)**: 한 게이트의 입력 수.
- **팬아웃(fan-out)**: 한 게이트 출력에 정상 동작하도록 연결할 수 있는 최대 입력 수.

팬아웃은 출력이 공급·흡수할 수 있는 전류와 각 입력이 요구하는 전류를 비교한다. **High와 Low를 각각 계산하고 더 작은 쪽**을 선택한다.

$$FO_H=\frac{|I_{OH}|}{|I_{IH}|},\qquad FO_L=\frac{|I_{OL}|}{|I_{IL}|}$$

분자·분모의 단위가 같아야 한다. 전압의 조건은 [[디지털 논리 회로/잡음 여유도]]에서도 확인한다.

## 자료의 74F00 예제

```text
High: 1mA / 20μA = 1mA / 0.02mA = 50
Low: 20mA / 0.6mA ≈ 33
→ 최악의 조건을 기준으로 팬아웃 33개
```

## 싱크와 소스

| 구분 | 전류 방향 | 자료의 LED 연결 |
|---|---|---|
| 싱크(sink) | 출력 쪽으로 전류가 흘러 들어감 | 전원 → 저항·LED → 출력 핀. 출력 Low에서 점등 |
| 소스(source) | 출력에서 바깥으로 전류가 흐름 | 출력 핀 → 저항·LED → 접지. 출력 High에서 점등 |

자료는 TTL의 싱크·소스 구동 능력이 다를 수 있다고 설명하며, 많은 74계열의 싱크는 16mA까지, 소스는 0.25mA 이하라는 예를 든다. 구동 예에는 [[디지털 논리 회로/NOT과 버퍼|버퍼]] 74LS06·74LS07도 제시된다.

**논리값이 맞아도 전류를 충분히 구동할 수 있는지 별도로 확인해야 한다.** IC 계열과 관련 기호는 [[디지털 논리 회로/TTL CMOS와 집적회로]]에서 읽는다.
