# 아날로그와 디지털 시스템

출처: 자료 I, 3~6쪽 · [[디지털 논리 회로/00 디지털 논리 회로 길잡이|길잡이]]

## 신호와 시스템

| 구분 | 아날로그 | 디지털 |
|---|---|---|
| 정보 | 연속적으로 변하는 값 | 서로 구별되는 이산적인 값 |
| 신호 예 | 온도, 습도, 소리, 빛 | 논리 0과 1로 표현하는 신호 |
| 시스템 | 연속 정보를 입력받아 처리하고 연속 정보 출력 | 이산 정보를 가공하여 필요한 정보 출력 |

**이산적**이라는 것은 값이 연속해서 이어지지 않고, 구별되는 개별 단위로 존재한다는 뜻이다. 디지털 정보의 기본 단위는 [[디지털 논리 회로/디지털 정보와 데이터 단위|비트]]이며, 회로에서는 [[디지털 논리 회로/논리 레벨과 정논리 부논리|전압 범위]]를 0과 1에 대응시킨다.

## 디지털 시스템의 장점

- **잡음 내성**: 작은 전압 변화가 논리값을 바꾸지 않을 수 있다. 관련 특성은 [[디지털 논리 회로/잡음 여유도]]이다.
- **저장·복제 용이**: 메모리와 파일로 정보를 저장하고 같은 정보를 반복 복제할 수 있다.
- **프로그래밍 가능**: 소프트웨어·HDL을 변경해 기능을 수정할 수 있다.
- **정해진 논리 처리**: 산술·비교·상태 제어·병렬 처리를 규칙에 따라 수행한다.
- **집적화**: 많은 트랜지스터를 작은 면적에 넣어 소형 시스템을 만든다. [[디지털 논리 회로/TTL CMOS와 집적회로|집적회로]]와 연결된다.

## 현실의 신호와 연결

현실의 정보는 대부분 아날로그이고 컴퓨터·FPGA·MCU는 디지털로 처리한다. 입력과 출력 사이를 [[디지털 논리 회로/ADC와 DAC]]가 연결한다.

```text
아날로그 입력 → ADC → 디지털 처리 → DAC → 아날로그 출력
```

자료에서는 FPGA 실습의 입출력 예로 센서, 스위치, PWM, UART도 소개한다. PWM의 기본 파형은 [[디지털 논리 회로/펄스 파형과 주파수 듀티사이클]]에서 확인한다.
