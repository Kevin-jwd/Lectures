# FPGA와 RTL 설계

출처: PDF 3–12쪽 · [[Vivado/00 Vivado 디지털 회로 설계 길잡이|길잡이]]

## FPGA

**FPGA(Field Programmable Gate Array)는 사용자가 원하는 디지털 회로로 구성을 변경할 수 있는 소자**이다. 논리 블록과 연결 구조를 구성하여 회로를 구현한다.

- 일부 기능은 메모리 컨트롤러·고속 통신·PCIe 등의 하드 블록으로 제공된다.
- 자료의 활용 예: ASIC 프로토타이핑, 영상·음성 처리, 산업·의료 장비, AI 연산, 네트워크 처리.
- FPGA 프로그래밍은 CPU가 실행할 명령을 작성하는 것과 달리 **하드웨어의 논리와 연결 구조를 설계하는 작업**이다.

## HDL과 RTL

HDL(Hardware Description Language)은 회로의 구조와 동작을 기술하는 언어이다. 복잡한 회로를 회로도로만 설계하는 어려움을 줄이고, 모듈 단위로 재사용할 수 있게 한다.

| 구분 | 핵심 |
|---|---|
| Verilog HDL | C와 비슷한 문법, 파일 확장자 `.v` |
| VHDL | 또 다른 하드웨어 기술 언어 |
| 구조적 기술 | 구성 요소와 연결 관계를 표현 |
| 동작적 기술 | 입력 변화에 따른 회로의 동작을 표현 |

**RTL(Register Transfer Level)은 레지스터 사이의 데이터 전달과 그 과정의 논리 연산을 중심으로 회로를 표현하는 수준**이다.

```text
레지스터 → 조합논리(가산기·멀티플렉서 등) → 레지스터
   저장            연산·선택                 다음 클록에 저장
```

자료의 RTL 구성 요소는 레지스터(Register), 전달(Transfer), 논리 연산(Logic)이다. 상태 저장과 클록의 역할은 [[디지털 논리 회로/조합논리와 순차논리]]와 연결된다.

## 설계 결과가 FPGA에 들어가는 과정

HDL로 기술한 회로는 [[Vivado/합성과 구현|합성과 구현]]을 거쳐 [[Vivado/비트스트림과 보드 프로그래밍|비트스트림]]으로 만들어진다. 실습 대상 소자는 [[Vivado/Basys3 보드와 FPGA 구성|Basys3의 Artix-7 FPGA]]이다.

문법과 연결 방법은 [[Vivado/Verilog 모듈과 게이트 회로]]에서 확인한다.
