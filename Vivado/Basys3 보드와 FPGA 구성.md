# Basys3 보드와 FPGA 구성

출처: PDF 14–19쪽 · [[Vivado/00 Vivado 디지털 회로 설계 길잡이|길잡이]]

## 보드와 주요 자원

Basys3는 **Artix-7 35T FPGA**를 사용하는 디지털 회로 실습 보드이다.

| 자원 | 자료의 설명 |
|---|---|
| Slice | 5,200개, 각 Slice에 6입력 LUT 4개와 플립플롭 8개 |
| Logic cell | 33,280개 |
| Block RAM | 1,800 Kbit |
| DSP Slice | 90개 |
| 클록 관련 자원 | Clock tile, PLL |
| 외부 입출력 | 스위치, LED, 버튼, 7세그먼트 표시기, Pmod 등 |

LUT·플립플롭을 활용하는 과정은 [[Vivado/합성과 구현]]에서 확인한다. 보드 입출력은 [[Vivado/XDC 핀 제약과 포트 매핑|XDC]]로 HDL 포트에 연결한다.

## 보드 클록

- 기본 발진기: **100 MHz**
- FPGA 핀: **W5**, Bank 34의 MRCC 입력
- 주기: **10 ns**

주파수와 주기의 관계는 [[디지털 논리 회로/펄스 파형과 주파수 듀티사이클]]과 연결된다. 이 자료의 게이트 실습은 조합논리이므로 별도 클록 입력을 사용하지 않는다.

## FPGA 구성 정보

**비트스트림은 FPGA의 논리 기능과 연결을 정하는 구성 데이터**이다. FPGA 내부 SRAM에 저장되는 구성은 전원이 꺼지면 사라진다.

| 구성 방법 | 구성 데이터 전달 방식 |
|---|---|
| USB-JTAG | PC에서 J4의 PROG 포트를 통해 다운로드 |
| SPI Flash | 비휘발성 Flash에 저장하고 부팅 시 FPGA로 로드 |
| USB HOST | USB 메모리의 비트스트림을 읽어 구성 |

보드에 다운로드하는 절차와 Flash·USB 방식의 조건은 [[Vivado/비트스트림과 보드 프로그래밍]]에서 확인한다.
