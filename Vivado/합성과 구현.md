# 합성과 구현

출처: PDF 36, 42–46쪽 · [[Vivado/00 Vivado 디지털 회로 설계 길잡이|길잡이]]

## 전체 흐름

```text
RTL 코드
  → Elaboration: 회로 구조 해석
  → Synthesis: 논리 최적화와 FPGA 자원 매핑
  → Implementation: 실제 자원 위치 배치와 배선
  → Bitstream: FPGA 구성 파일 생성
```

**합성은 회로를 어떤 자원으로 만들지 정하는 과정이고, 구현은 그 자원을 어디에 놓고 어떻게 연결할지 정하는 과정**이다.

## 합성(Synthesis)

Vivado의 `Run Synthesis`를 실행한다. 자료에서는 다음 세 단계로 설명한다.

| 단계 | 역할 |
|---|---|
| RTL 분석·Elaboration | 문법과 모듈 구조를 해석하고 회로 연결을 구성 |
| Logic Optimization | 중복 논리, 사용하지 않는 논리, 상수 조건 등을 정리 |
| Technology Mapping | 대상 FPGA의 LUT·플립플롭 등으로 논리를 매핑 |

예를 들어 [[Vivado/Verilog 모듈과 게이트 회로|게이트 모듈]]의 논리는 [[Vivado/Basys3 보드와 FPGA 구성|Basys3 FPGA 자원]]으로 변환된다.

## Netlist

**Netlist는 회로 요소와 요소 사이의 연결(Net)을 기술한 목록**이다.

| 단계 | Netlist에서 보는 내용 |
|---|---|
| Elaboration 후 | RTL 코드로 해석한 회로 구조 |
| 합성 후 | LUT·플립플롭 등으로 매핑된 논리 요소와 연결 |
| 구현 후 | 실제 자원 배치·배선과 타이밍 정보 |

`Open Elaborated Design`에서 본 회로도는 코드를 해석한 구조이며, 아직 최종 물리 배치·배선은 아니다.

## 구현(Implementation)

`Run Implementation`을 실행한다. [[Vivado/XDC 핀 제약과 포트 매핑|제약 조건]]을 반영하여 실제 FPGA에 회로를 배치하고 연결한다.

| 작업 | 역할 |
|---|---|
| Opt Design | 구현에 앞서 논리 구조를 최적화 |
| Power Opt Design | 전력 관점의 최적화, 선택적으로 수행 |
| Place Design | LUT·플립플롭·RAM·DSP 등을 실제 위치에 배치 |
| Phys Opt Design | 물리 배치 관점에서 타이밍·연결 등을 최적화 |
| Route Design | 배치된 요소 사이의 실제 배선 경로를 결정 |

자료의 단계 구분을 정리한 것으로, 선택한 실행 설정에 따라 수행되는 최적화 작업은 달라질 수 있다.

구현 이후는 [[Vivado/비트스트림과 보드 프로그래밍]]으로 이어진다. 타이밍 화면 확인은 [[Vivado/Vivado 2022.2 유용한 단축키]]를 참고한다.
