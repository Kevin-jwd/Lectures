# 비트스트림과 보드 프로그래밍

출처: PDF 16–17, 47–51쪽 · [[Vivado/00 Vivado 디지털 회로 설계 길잡이|길잡이]]

## 비트스트림 생성

**비트스트림(.bit)은 설계한 회로를 FPGA에 구성하기 위한 파일**이다. [[Vivado/합성과 구현|구현]]을 마친 뒤 `Generate Bitstream`으로 생성한다.

논리 기능뿐 아니라 구현된 연결 구조가 FPGA의 구성 정보로 들어간다. CPU에서 실행할 일반 프로그램 파일과 구분한다.

## JTAG 다운로드

1. Basys3 전원을 켜고 PC와 USB-JTAG의 **PROG 포트(J4)**를 연결한다.
2. Vivado에서 `Open Hardware Manager`를 연다.
3. `Open Target`으로 보드와 연결한다.
4. FPGA 장치의 `Program Device`를 선택한다.
5. 생성된 `.bit` 파일을 지정하고 `Program`을 실행한다.
6. 스위치를 조작하고 LED가 [[Vivado/Verilog 모듈과 게이트 회로|게이트 논리]]대로 켜지는지 확인한다.

Target이 보이지 않으면 보드 전원, USB 포트·케이블, 케이블 드라이버를 확인한다. PDF의 드라이버 경로는 버전별 설치 폴더 아래의 다음 위치이다.

```text
C:\Xilinx\Vivado\2022.2\data\xicom\cable_drivers\nt64\digilent
```

## 전원이 꺼진 뒤에도 유지하려면

[[Vivado/Basys3 보드와 FPGA 구성|FPGA SRAM의 구성 정보]]는 전원이 꺼지면 사라진다. **JTAG로 .bit를 다운로드한 것만으로 Flash에 저장되는 것은 아니다.**

| 방식 | 자료의 구성 절차·조건 |
|---|---|
| SPI Flash | Flash 쓰기를 위한 FPGA 구성 후 데이터를 전송하여 비휘발성 메모리에 저장. 전원 투입·재구성 시 모드 설정에 따라 FPGA로 로드 |
| USB HOST | FAT32 USB 메모리의 루트에 `.bit` 파일 하나를 저장하고 J2에 연결. JP1을 USB 모드로 설정하고 PROG 버튼 또는 전원 재인가로 구성 |

PDF는 Flash 프로그래밍을 후속 실습 항목으로 표시하므로 세부 클릭 절차는 여기서 확장하지 않는다.

보드 동작이 예상과 다르면 논리 검증은 [[Vivado/테스트벤치와 시뮬레이션]], 입출력 연결은 [[Vivado/XDC 핀 제약과 포트 매핑]]에서 각각 확인한다.
