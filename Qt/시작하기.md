#### UI
<br>

- <b>User Interface</b>
	- HW와 Sw 요소를 포함

<br>

- <b>CLI, Command Line Interface</b>: 시스템 콘솔에 연결된 배치 모니터 사용
	- 거의 실시간 상호작용 가능
- <b>TUI, Test-based User Interface</b>: GUI처럼 화면 전반을 사용 -><i>Mdir, Vim</i>
- <b>GUI, Graphic User Interface</b>: 버튼이나 윈도우 같은 그래픽 요소 사용
	- 직관적인 사용 가능

<br>

#### Qt
<br>

- Windows, macOS, Linux를 모두 지원하는 C++ 프레임워크
- <b>Qt Creator</b>: Qt 프레임워크 개발을 위한 IDE

<br>

#### 기본 구조
<br>

```C++
/* main.cpp */
int main(int argc, char *argv[])
{
    QApplication a(argc, argv);   // GUI 어플리케이션은 1개의 QApplication 객체 필요
    MainWindow w;                 // MainWindow 객체 생성
 
    w.show();                     // MainWindow를 화면에 표시
    return QApplication::exec();  // 메인 이벤트 루프 처리 -> exit()가 호출되면 return 
}
```
<br>

```C++
/* mainwindow.h */
QT_BEGIN_NAMESPACE
namespace Ui { class MainWindow; }   // UI 파일(mainwindow.ui)로부터 생성되는 클래스의 전방 선언
QT_END_NAMESPACE                    

class MainWindow : public QMainWindow   // QMainWindow를 상속
{
    Q_OBJECT   // Qt 라이브러리를 원활하게 사용하기 위해
               // 관련 멤버를 포함시키는 매크로 (시그널/슬롯, 메타오브젝트 기능 활성화)

public:
    explicit MainWindow(QWidget *parent = nullptr);  // 생성자
                                      // parent: 부모 위젯, 없으면 nullptr(최상위 창)
                                      // explicit: 암시적 형변환 방지
    ~MainWindow() override;                          // 소멸자
                                      // override: 부모의 가상 소멸자를 재정의함을 명시

private:
    Ui::MainWindow *ui;   // UI 위젯들에 접근하기 위한 포인터
                          // 예) ui->pushButton, ui->label 등
};
```
